## 3. Live Visible `GhostBrowser.exe` One-by-One Audit & Newly Uncovered Fixes

All 55 websites were navigated and inspected one-by-one in the visible `GhostBrowser.exe` desktop window (`WinSta0\Default`). During the live one-by-one walkthrough, the following subtle browser-engine invariants were uncovered and hardened in [`ghost_engine_core.js`](file:///D:/GhostBrowser-Windows-Android/Resources/Scripts/ghost_engine_core.js), [`anti_fingerprint.js`](file:///C:/Users/Home/Desktop/app/GhostBrowser/Resources/anti_fingerprint.js), and [`EngineAutomationService.cs`](file:///D:/GhostBrowser-Windows-Android/Services/EngineAutomationService.cs):

1. **Kasada KPSDK (`cdndex.io` `ips.js`) Bytecode VM Telemetry Probes on Chewy (`https://www.chewy.com`)**:
   - **`elc` (`Error.stackTraceLimit` Line Count)**: When `Function.prototype.toString.call(1)` throws `TypeError`, V8 captures at most `Error.stackTraceLimit` (`10`) frames before `scrubHookStack(err)` runs. Because internal hook frames (`invokeNativeWithCleanStack`, `toString`) consumed 2 of the 10 slots, scrubbing left `9` stack lines instead of `11` (`1` header + `10` frames). We now temporarily bump `Error.stackTraceLimit` by `+6` during hook invocation, restore `Error.stackTraceLimit` in `catch`/`finally`, and cap the scrubbed stack at `1 + Math.floor(origLimit)` (`11` lines).
   - **`fsc` (`class kekko extends Function.toString {}`) & `/tl` (`class Blah extends WebGL2RenderingContext.prototype.getParameter {}`)**: V8's C++ `Runtime_ThrowNotConstructor` formats non-constructor `class extends` `TypeError.message` strings using C++ `JSFunction::ToString` (bypassing `Function.prototype.toString`), which previously exposed `holder[name]` source code instead of `function toString() { [native code] }`. By wrapping `origNativeFn` in `new _origProxy(origNativeFn, { apply(...) })` inside `makeNative(fn, name, length, origNativeFn)`, V8 inspects `[[ProxyTarget]]` (the genuine C++ builtin) and formats `"Class extends value function toString() { [native code] } is not a constructor or null"` — 100% identical to native Chrome.
   - **`esce` (`String.prototype.toString.call(fn)` Stack Frame)**: Hooked `String.prototype.toString` (`_customStringToString` / `_hookedStringToString`) to unwrap internal proxies via `_proxyTargetMap` before invoking native `String.prototype.toString`, ensuring the top stack frame reads `at toString.toString (<anonymous>)` rather than `at Proxy.toString (<anonymous>)`.
   - **Live Result on `https://www.chewy.com`**: Passed Kasada (`KP_UIDz`, `KP_UIDz-ssn`) + Akamai Bot Manager (`bm_s`, `bm_so`) + FingerprintJS Pro (`fppro_id`, `_vid_t`) on the first navigation (`"Pet Food, Products and Supplies at Low Prices - Free Shipping"`, 48 cookies).
2. **Unsolicited Client Hints Header Guard in `EngineAutomationService.cs`**:
   - Replaced unconditional `headers.SetHeader(...)` calls in `WebResourceRequested` with `SetHeaderIfChanged(headers, name, val)` so Client Hints headers (`sec-ch-device-memory`, `sec-ch-dpr`, `ect`, `rtt`, `downlink`) are only harmonized when Chromium actually sends them on the wire (preventing unsolicited Client Hints on `www.google.com` or subresources).
